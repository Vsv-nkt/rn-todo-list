# Todo App v2.0

Розширена версія додатку списку завдань на **React Native (Expo Router)** з таб-навігацією, статистикою та динамічною темою.

## 🎯 Реалізовані функції

### 📝 Вкладка «Завдання»
- Додавання нових завдань через форму з `TextInput`.
- Позначення завдань виконаними (клік на іконку).
- Редагування тексту завдання (клік на текст → поле вводу).
- Видалення завдань через іконку кошика.
- Лічильник виконаних завдань у заголовку.

### 📊 Вкладка «Статистика»
- 4 аналітичні картки:
  - **Всього завдань** — загальна кількість.
  - **Активні** — кількість невиконаних.
  - **Виконані** — кількість виконаних.
  - **Прогрес** — відсоток виконання.
- Розрахунки оновлюються автоматично при будь-якій зміні списку.

### ⚙️ Вкладка «Налаштування»
- Перемикач **Світла / Темна тема** (`Switch`).
- Кнопка **«Очистити виконані»** з підтвердженням через `Alert.alert`.
- Кнопка **«Видалити всі»** з підтвердженням.
- Інформація про додаток (назва, версія).

### 🎨 Система тем
- Глобальний `ThemeContext` + хук `useTheme()`.
- Кольори всього додатку адаптуються миттєво: фон, карточки, текст, таб-бар, статус-бар.
- Вибір теми зберігається в `AsyncStorage` під ключем `@todo_theme_mode`.

### 💾 Збереження даних
- Список завдань зберігається в `AsyncStorage` під ключем `@todos_list`.
- Дані залишаються після перезавантаження додатку.
- Спільний стан через `TodoContext`.

### 🧭 Таб-навігація
- **Expo Router** з файловим роутингом.
- 3 вкладки з іконками з `@expo/vector-icons` (Ionicons).
- Активна вкладка підсвічується акцентним кольором теми.
